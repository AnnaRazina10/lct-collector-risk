# Read-only аудит локального review-пакета

Проверено 29.09.2026. Все 33 проверок прошли; блокирующих ошибок состава, frozen-зависимостей или сохранения runtime-базы в коде запуска не найдено. Установка, сервер и inference в этом аудите не запускались.

- ZIP: `5790cd08e3c24e3d8dda8520d56b59756e99077b7df120b1f24190e3a61e24c4`, 4,441,558 байт; 67 файлов, из них 66 перечислены в manifest. Пути безопасны, дублей/symlink нет; все размеры и SHA совпали. Manifest честно помечает изменения рабочего дерева и не выдаётся за подпись.
- Состав точно соответствует allowlist и отслеживаемым src/api/web. Две модели, два дневных parquet, два разрешённых справочника; исходных 7z, окружения, ключей и credential-совпадений по проверенным шаблонам не найдено.
- В seed только `forecast_runs` и `forecast_card_ids`: 6 проверенных выпусков, 468 уникальных карточек, 3 выпуска каждой цели; есть триггеры неизменяемости. Таблиц feedback/tickets нет. Все replay payload прошли проверку hash/метаданных и запрета будущих исходов.
- Все frozen sources из onset refit, pinned refit/selection, выбранная joblib-модель, прежняя any-alarm модель и словари присутствуют с правильными SHA. Отсутствующий combined/selection и прочие модели нужны обучению/оценке, которые пакет прямо не обещает.
- Launcher копирует seed во временный файл только при отсутствии `dispatch.sqlite3`, публикует hard link без замены и при конкурентном FileExistsError сохраняет уже появившуюся базу. Повторный запуск не копирует seed поверх существующих решений. Действующая база исключена из immutable manifest. Неподдерживаемые hard links дадут ошибку; универсальная поддержка файловых систем не заявлена.

Неблокирующее уточнение: START_HERE приписывает необходимость macOS OpenMP пути «runtime/inference». Архивный API не импортирует LightGBM и не требует OpenMP; зависимость нужна дополнительному inference. Linux/Windows явно обозначены непроверенными, полное переобучение не заявлено.

Границы: сохранность launcher проверена чтением/AST, не новой записью базы; реальные clean-install/restart/inference проверки выполняет root отдельно. Автономные legacy JSON содержат раскрываемые архивные исходы по прежнему контракту; шесть replay-выпусков таких полей не имеют. ZIP не изменялся и не публиковался.
