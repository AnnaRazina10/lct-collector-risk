# Статистические альтернативы: протокол до обучения

29.09.2026. Цель — любая зарегистрированная тревога объекта в D+2, выдача D+1 00:00, окно +24…+48 ч. Одинаковый объектный набор object_risk_probe, без замены физической поломкой. Статическая справочная принадлежность каналов остаётся ограничением.

На этом этапе читается только история до 30 ноября 2025. Train: feature date <=28 сентября; tune: 1 октября–28 ноября. Декабрь и 2026 не используются. Проверка включает повторное воспроизведение сохранённого LightGBM-контроля на тех же строках.

Кандидаты: два срока забывания адаптивной трёхсостоянийной цепи Маркова (нет записи / есть запись без тревоги / тревога), прогноз на два шага; сглаженная частота объекта по дню недели; регуляризованная логистическая авторегрессия и аддитивные сплайны. Окна и параметры ограничены исходным кодом до обучения. Для обучаемых преобразований используется только train. Статистики последовательности принимают лишь известные события до дня признаков включительно.

Критерий отбора — AP на tune. Precision/Recall на tune описательные, их порог не применяется к будущей проверке без отдельного декабря. Сохранённые кандидаты будут рассмотрены вместе с независимым GRU-экспериментом; итоговая смесь, refit, декабрьский порог и повторная диагностика 2026 — отдельный зафиксированный этап, без выбора по тесту. Победа над старым объектным контролем не объявляется улучшением канальной задачи.
