Train до 28.09.2025; tune 01.10–28.11.2025; цель — тревожная запись на D+2. Декабрь и 2026 не использовались для выбора. Калибровка и refit не выполнялись.

В выполненном запуске `prepare` материализовал историю до 31.12.2025, после чего строки декабря были удалены **до** scaler, построения окон, обучения и выбора. Физический файл 2025 года прочитан целиком. Поэтому утверждение «декабрь не читался» было бы неверным. Все используемые feature days закончились 28.11; целевые метки — 30.11. Для будущих запусков reader ограничен `prepare(end_date='2025-11-30')`.

Самостоятельная GRU уступила LightGBM на 0,051287 AP. Окно 28 дней улучшило AP относительно замороженной частоты объекта на 0,036058, однако такого результата недостаточно для замены текущего бустинга. Проверка заранее ограниченной смеси остаётся отдельным последующим экспериментом.

Обе сети имеют по 4 577 параметров. Обучение с проверкой сохранения заняло 27,70 с / 55,30 с на CPU, 3 потока. Каждая сеть выполнила 40 полных эпох; лучшие веса обеих получены на полной эпохе 36. Ограничение времени ни разу не прервало эпоху. Исходный код выполненного эксперимента сохранён в `source_at_training.py`, его SHA совпадает с `configuration.json`. После запуска в рабочий модуль добавлены запрет выбора неполной эпохи и отдельная функция refit; эти изменения не меняют сохранённые результаты.

Проверки окон: будущие изменения не влияют на прошлые окна, scaler обучен только на train. Сохранённые модели воспроизводят все прогнозы tune с отклонением не более 1e-7.

Порог max-F1 выбран на том же tune и не является независимой финальной оценкой. День без тревоги в момент выдачи не исключает начала события в промежуточный D+1. Цель описывает зарегистрированную тревогу, не подтверждённую физическую аварию.

## API для следующего этапа

`predict = load_predictor(checkpoint_path); score = predict(history_frame.reset_index(drop=True), positional_indices)` принимает историю до произвольных прогнозируемых feature days. История каждого объекта должна быть отсортирована и непрерывна по дням; target для inference не требуется. В начале истории окна дополнены нулями и отдельной маской фактических дней.

`refit_fixed_epochs(history_frame, checkpoint_path, feature_end, label_end, output_path)` доступен для отдельного явного вызова. Функция проверяет, что исходная лучшая эпоха была полной, обучает новую модель с нуля ровно столько полных эпох, проверяет D+2-метки по `alarm_today`, обучает scaler только до `feature_end` и сохраняет новый файл. Данные должны включать `label_end >= feature_end + 2 days`; в refit нет validation и ранней остановки. Функция **не запускалась**.
