# Совместное сравнение объектных подходов

Зафиксировано до расчёта смесей и повторной проверки будущего периода. Все ранее использованные данные 2026 уже известны исследовательскому процессу; никакой новой слепой проверки не заявляется.

Единица — объект-день, цель — зарегистрированная тревога на D+2. Момент выдачи D+1 00:00; окно +24…+48 часов. Ключи и цели всех tune-прогнозов должны совпасть точно.

Пул одиночных моделей: прежний LightGBM (контроль), лучшая по tuneAP в каждой из четырёх статистических групп (Markov, seasonal, linear, spline), лучшая из GRU 28/56 дней. Смеси: для каждой неконтрольной модели веса контроля 0.25/0.5/0.75; равная смесь LightGBM + лучшая статистическая + лучшая GRU. Другие веса после расчёта не добавляются. Отбор — AP октября–ноября 2025.

После отбора: фиксировать состав смеси и параметры; дообучить выбранные компоненты и контроль по признакам не позднее 28.11.2025 (метки заканчиваются 30.11). Для статистических моделей обновить только обучаемые prior/коэффициенты на том же периоде; причинная статистика продолжает обновляться по известным событиям. Нейросеть дообучается с нуля фиксированным числом полностью завершённых лучших эпох. LightGBM использует прежние 167 деревьев.

Порог каждого сравниваемого финального прогноза — max-F1 на 01–29.12.2025, метки до31.12. В декабре нельзя менять смесь, признаки, число деревьев или эпох. Итоговый период: feature days 31.12.2025–28.06.2026, issue days 01.01–29.06.2026, target days 02.01–30.06.2026 — те же 14 040 объект-дней, что прежний forward-check.

Показать выбранную смесь, сопоставимо дообученный контроль и прежний замороженный контроль отдельно. Дополнительно показать заранее заданные бюджеты top5/top10/top20 объектов в день, без выбора лучшего бюджета по тесту. Основные метрики AP, P/R/F1, FP/день; отдельные месяцы, cohort quiet-at-feature-day и описательные интервалы по недельным блокам.
