# Протокол второй итерации — зафиксирован до результатов

28.09.2026. Предыдущая итерация и test2026 уже просмотрены; повторный test — сравнительная диагностика, не новый слепой тест.

- Основная цель неизменна: хотя бы одно тревожное сообщение на следующий календарный день для исходной сетки каналов/дат. Прогноз выпускается после окончания дня признаков.
- Обучение: январь–29 сентября2025. Настройка итераций, кандидатов и ансамбля: 1октября–29ноября2025. Порог фиксируется на 1–30декабря2025 после выбора модели. Зазоры исключают пересечение меток через границы.
- Новые признаки строятся только из текущих и прошлых наблюдений: лаги, серии, экспоненциальные оценки, переходы состояний, отклонения от прошлого режима, контекст объекта/типа/родителя. Prior до2025 допустим для всех строк2025+.
- Кандидаты: предыдущая сохранённая модель как контроль, два LightGBM различной сложности, два CatBoost (глубина/давность обучения), модели по инженерным системам. При готовности прошлой истории — те же модели с prior до2025.
- Смешивания: заранее заданные веса 0.25/0.5/0.75 для двух лучших новых моделей; равные веса лучших трёх. Весовой подбор только на октябре–ноябре. Сравнивать AP и одновременно достижимые P/R; порог не меняет AP.
- Выбор максимального AP на настройке, затем замороженный порог maxF1 на декабре. Никакого выбора на2026. Модель и конфигурация фиксируются до теста.
- Однократная итоговая проверка выбранного кандидата на прежних1.2млн testстрок2026. Показать отдельно P/R, месяцы и группу без текущей тревоги. Если выбранный по validation вариант ухудшится наtest, сохранить результат и не выбирать другой поtest.
- Иные цели (технический эпизод, +24…+48ч) только отдельная исследовательская диагностика, не подмена улучшения прежней задачи.

Дополнение до запуска кандидатов: один ограниченный TabM с обработкой признаков только наtrain и оценкой на том жеtune; может войти в смеси при наличии полного воспроизводимого inference. Внутридневные причинные признаки (последнее состояние, время последней тревоги, последние6/12часов) — отдельная группаобогащения, при готовности кеша включается до начала обучения. Обучающие внешние данные не используются.

До первого обучения добавлены две абляции LightGBM31: без внутридневных признаков и без старой истории. Профиль2019–2024 заморожен вchannel_prior_frozen_v2.parquet; версии не меняются в ходе эксперимента.

Контрольv1 только для сравнения: он использовал декабрь при прежнем early stopping, поэтому не допускается в новые смеси или выбор победителя.

Смеси также включают лучшую CatBoost+лучшую LightGBM и TabM+лучшую LightGBM с теми же заранее заданными весами0.25/0.5/0.75. Все веса оцениваются на одном Oct–Nov, итоговый test только после фиксации.

Перед раскрытием новой декабрьскойоценки и test уточнён финальный шаг: после выбора параметров/смеси наOct–Nov дообучить выбранные древесные компоненты на данных до29.11.2025 с фиксированным числом деревьев, без early stopping на декабре. TabM при попадании в смесь остаётся замороженным. Декабрь служит только для порога. Такой refit использует более свежие обучающие данные; итоговый прирост относится ко всему конвейеру, а не только новым признакам. Первоначальные модели и tune-прогнозы сохраняются отдельно.
