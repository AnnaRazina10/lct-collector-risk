# Локальный комплект для проверки

Комплект предназначен для передачи внутри команды и локального запуска архивного прототипа. Он не опубликован: в ZIP находятся предоставленные дневные агрегаты, справочники и веса. Папка `artifacts/submission/bundles/` исключена из Git. Репозиторий с исходным кодом: https://github.com/AnnaRazina10/lct-collector-risk.

## Что входит

- Код API, интерфейса и моделей; фиксированные зависимости runtime/inference.
- Дневные агрегаты 2025 и 2026, два справочника, прежняя объектная модель и кандидат начала серии.
- Шесть неизменяемых выпусков: по три на каждую объектную цель; исходные карточки канальной и объектной демонстрации.
- Инструкция `START_HERE.md`, проверка SHA-256 и локальный запуск.

Восемь исходных архивов и все веса исследовательских кандидатов не включены. Комплект позволяет пересчитать два зафиксированных прогноза; полного переобучения всего исследования из одного ZIP он не обещает. Черновики заявок и решения пользователя не экспортируются. База `forecast_seed.sqlite3` содержит только выпуски и индексы карточек.

## Запуск после распаковки

Нужен Python 3.12. На macOS для LightGBM дополнительно используется системный OpenMP runtime; в проверенной среде установлен Homebrew `libomp`. Зависимости Python скачиваются из PyPI. Windows и Linux отдельно не проверены.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-runtime.txt
.venv/bin/python verify_bundle.py
.venv/bin/python start_demo.py --port 8765
```

Открыть `http://127.0.0.1:8765/`. В Windows путь к интерпретатору виртуального окружения: `.venv\Scripts\python.exe`. Если порт занят, выбрать другой через `--port`. Сервер доступен только локально; публичная ссылка этим запуском не создаётся.

При первом запуске seed копируется атомарно в отдельную `data/app/dispatch.sqlite3`. Следующие запуски сохраняют эту рабочую базу. Проверка контрольных сумм относится к исходным файлам, а не к новым пользовательским решениям. Контрольные суммы подтверждают совпадение файлов с манифестом, но не заменяют цифровую подпись отправителя.

## Пересчёт моделей

```sh
.venv/bin/python -m pip install -r requirements-inference.txt
.venv/bin/python src/serving/object_onset_forecast.py --database data/app/recomputed_onset.sqlite3
.venv/bin/python src/serving/object_forecast.py --database data/app/recomputed_any.sqlite3
```

Обучения и чтения будущих исходов для оценки не происходит. Фильтр истории заканчивается датой признаков каждого выпуска. Полный файл 2026 в комплекте содержит более поздние записи, но адаптер не включает их в признаки раннего выпуска. В отдельной проверке следует сравнивать оценки по дате и идентификатору объекта, а не предполагать одинаковый run_id при различном составе bootstrap/дневных пакетов.

Сборка в исходном репозитории: `.venv/bin/python scripts/build_review_bundle.py --output artifacts/submission/bundles/collector-risk-review.zip`. Существующий ZIP не перезаписывается; для повторной сборки нужно новое имя. Манифест внутри фиксирует версию Git, наличие незакоммиченных изменений при сборке, состав и хеш каждого файла. Итоги фактического запуска и пересчёта сохраняются в `reports/submission_readiness/`.

## Фактическая проверка, 29 сентября 2026

ZIP размером около 4,44 МБ распакован в новую папку вне рабочего проекта. Отдельное Python 3.12.14 окружение создано без системных site-packages; 25 пакетов установлены по `requirements-inference.txt` из официального PyPI. Обе модели пересчитали по три выпуска. Все 468 оценок и полные payload совпали с исходными; 66 входных файлов прошли проверку хешей. Подробности: `reports/submission_readiness/clean_inference.json`.

Сервер из этого окружения открыл шесть выпусков. Рабочая база изначально не содержала прежних заявок и решений. Явно тестовое решение пережило штатную остановку и повторный запуск; исходный seed и все входные файлы остались неизменными. Подробности: `reports/submission_readiness/bundle_http.json`. Проверен macOS arm64 с существующим OpenMP runtime; переносимость на чистый Linux/Windows и полный цикл обработки сырых архивов не проверялись.

Комплект не заменяет публичный прототип или подтверждение сдачи на платформе. Корпоративные роли, TLS, физические исходы и рабочий поток отсутствуют; все действия диспетчера здесь локальные и демонстрационные.
