До их получения доступны упаковка, воспроизведение и подготовка материалов сдачи.

Текущая проверка переноса не даёт основания заменять цель «Любая тревога»: выигрыш по началам сопровождается ростом предупреждений без тревоги. Страты D+1 используют только для анализа, будущая наблюдаемость не входит в выдачу. Тесты рекомендаций подтверждают сохранение фактов и версий, но не эффективность предотвращения физических отказов.
