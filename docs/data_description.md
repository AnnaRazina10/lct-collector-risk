| `тревожное` | Признак тревожного события. |

## Первичные выводы для ML

- Данные сильно несбалансированы: тревожные события в файле-примере составляют около
  0.12%.
- Нужна временная валидация, а не случайное разбиение.
- Базовая сущность прогнозирования: канал датчика или объект.
- Перспективные признаки: частота событий, частота тревог, длительность серий,
  интервалы между событиями, скользящие агрегаты, тип датчика, тип инженерной
  системы, объект, сезонность.
- Для production-подхода архивы стоит распаковывать в промежуточный формат Parquet,
  чтобы быстро строить фичи и витрины.
